# Portfólio Pessoal

**Aluno:** Guilherme Tisiani Acrani

## Descrição
Este projeto é um portfólio pessoal desenvolvido como atividade da Agenda 15. O site apresenta meu perfil, alguns projetos realizados durante os estudos e uma forma de contato.

## Tecnologias utilizadas
- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons

## Organização dos arquivos
- `index.html`: estrutura e conteúdo das páginas.
- `css/style.css`: estilos visuais e ajustes de responsividade.

## Como o projeto funciona
O portfólio é uma página única. O menu superior utiliza links para levar o visitante às seções Perfil, Projetos e Contato. O Bootstrap é utilizado para a navegação responsiva e para organizar o conteúdo em colunas que se ajustam ao tamanho da tela. O CSS próprio define as cores, espaçamentos, fontes e aparência dos cartões.

## Novo recurso implementado
Foi adicionada uma animação aos cartões da seção Projetos. Quando o visitante passa o mouse sobre um cartão, ele se desloca um pouco para cima, recebe uma sombra mais forte e destaca sua borda.

## Como o novo recurso foi implementado
O recurso foi criado no arquivo `css/style.css`, usando `transition` na classe `.project-card` e `transform`, `box-shadow` e `border-color` na regra `.project-card:hover`. Também foi incluída uma regra para respeitar visitantes que preferem movimento reduzido.
